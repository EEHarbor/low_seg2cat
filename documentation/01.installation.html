--- title: Installation ---

Installation

Low Seg2Cat matches URI segments to category URL titles and makes the matching category information available as template variables. After installation, configure Settings and use the Template Variables reference.

Compatibility

These instructions cover Low Seg2Cat 4.x. The package metadata lists ExpressionEngine 3 and PHP 5.6 as minimum versions. The changelog records ExpressionEngine 4, 5, and 6 support in 4.0.0 and ExpressionEngine 7 compatibility in 4.0.2. Use a release suitable for your ExpressionEngine and PHP versions.

The older ExpressionEngine 1 and ExpressionEngine 2 branches are historical versions and are no longer under development.

Installing Low Seg2Cat

  1. Download and extract the Low Seg2Cat package.
  2. Copy its low_seg2cat add-on folder into system/user/addons/, then confirm that addon.setup.php is directly inside the installed low_seg2cat/ folder. Use your configured system-directory location if it has been renamed.
  3. Open Add-Ons in the ExpressionEngine control panel and install Low Seg2Cat. Control-panel labels vary between supported ExpressionEngine releases.
  4. Open Low Seg2Cat's settings and review the category groups and other options.
  5. Visit a page whose URI includes a category URL title and check the corresponding template variable.

Updating Low Seg2Cat

  1. Back up your site's database and files, and test the update on a copy of your site.
  2. Read the changelog for the release you are installing.
  3. Replace the existing system/user/addons/low_seg2cat/ files with the new package's add-on files.
  4. Open Add-Ons and complete any update action shown by your ExpressionEngine version. Low Seg2Cat's extension update runs when ExpressionEngine processes its version change. Do not uninstall the add-on as an update step.
  5. Check the saved settings and a template that uses the category variables.

Settings

The Settings reference covers Search all sites, Category groups, URI pattern, Set all segments, Ignore pagination, and Parse file paths, including their defaults.

Template Variables

Use the Template Variables reference for numbered-segment variables, last-segment variables, and combined category-ID lists. It also explains empty results and provides literal template examples.

Duplicate category URL titles

If more than one category has the same URL title, Low Seg2Cat can return only one matching category for that title. Do not rely on which duplicate is chosen. Keep category URL titles unique within the searched sites and groups, or restrict Category groups to remove the ambiguity. Search all sites ignores that group restriction.
