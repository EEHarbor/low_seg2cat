--- title: Settings ---

Settings

Open Low Seg2Cat's settings from Add-Ons in the ExpressionEngine control panel. These options determine which categories match URI segments and how the template variables are populated.

Search all sites

Default: No

When set to No, category matching is limited to the current ExpressionEngine site and the selected Category groups. When set to Yes, categories from all sites are searched and the Category groups selection is ignored.

Category groups

Default: All category groups

Select the groups to search within the current site. With no groups selected, all groups in that site are eligible. This setting has no effect while Search all sites is Yes.

Limit the search to groups with unique category URL titles. When duplicate titles exist in the searched categories, Low Seg2Cat returns one category for the title, with no guaranteed choice between duplicates.

URI pattern

Default: Blank

Leave this blank to allow all URIs. Otherwise, enter a valid regular expression including delimiters. Low Seg2Cat registers its variables only when the URI matches. For example, this pattern allows a URI containing an articles segment:

#(^|/)articles(/|$)#

A nonmatching URI skips variable registration entirely; Set all segments does not override this restriction. If Ignore pagination is enabled, its trailing pagination segment is removed before the pattern is checked.

Set all segments

Default: Yes

When set to Yes, initialize numbered category variables up to ExpressionEngine's configured max_url_segments value, using 12 when that configuration value is unset or empty. Segments without a matching category receive empty values.

When set to No, initialize variables only for the segments present in the URI. A request with no segments does not register Low Seg2Cat variables in this mode.

Ignore pagination

Default: No

When set to Yes, remove a trailing slash followed by P or C and digits from Low Seg2Cat's URI lookup, such as /P20 or /C20. For /articles/news/P20, the last-segment variables can then describe news instead of the pagination segment. This affects Low Seg2Cat's lookup; it does not change ExpressionEngine's standard segment variables.

Parse file paths

Default: No

When set to Yes, pass Category Image values through ExpressionEngine's file-path parser so that supported references such as {filedir_1}category.jpg can become usable paths. When set to No, return the stored Category Image value. The formats understood by that parser depend on your ExpressionEngine version.
